# git_cmd_toolkit

A lightweight Git workflow helper for Windows Git Bash.

This project provides a quick command panel for common Git tasks, including repository setup, daily commits, branch switching, and routine inspection commands.

## Environment

- Windows
- Git Bash / MinGW64

## Quick Start

```bash
source git-auto-setup.conf
git cmd
```

## What It Covers

- Initial repository setup
- Daily add / commit / pull / push workflow
- Remote branch tracking and switching
- Common Git inspection and recovery commands

## File

- `git-auto-setup.conf`: registers the `git cmd` alias and prints the workflow panel
